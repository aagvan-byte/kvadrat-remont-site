# Квадрат — сайт компании по ремонту квартир

Многостраничный сайт для ремонтной компании с формой заявки, которая приходит в Telegram. Демо-проект для портфолио, компания вымышленная.

## Что внутри

- 5 страниц: главная, услуги, наши работы, цены (с FAQ), контакты
- Форма заявки на каждой странице — заявка мгновенно приходит в Telegram с пометкой, с какой страницы
- Серверная обработка заявок: проверка данных, защита от спам-ботов, токен бота скрыт от посетителей
- Активный пункт меню, мобильное меню, адаптивная вёрстка
- Все тексты и цены в одном файле — легко адаптировать под клиента

## Стек

[Astro](https://astro.build) · [Tailwind CSS](https://tailwindcss.com) · [Vercel](https://vercel.com) (хостинг + серверная функция) · Telegram Bot API

## Запуск

```sh
npm install
cp .env.example .env   # впишите токен бота и ID чата
npm run dev            # http://localhost:4321
```

## Настройка Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Напишите боту любое сообщение и узнайте ID чата.
3. Впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env` локально и в Environment Variables на Vercel.

Если Telegram доступен только через VPN/прокси, запускайте локально `npm run dev:proxy` — Node возьмёт прокси из переменной `HTTPS_PROXY`.

## Как адаптировать под клиента

Тексты, услуги, цены и контакты — `src/data/site.ts`. Цвета и шрифты — `src/styles/global.css`.
